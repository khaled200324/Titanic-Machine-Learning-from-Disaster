# Titanic-Machine-Learning-from-Disaster

This project explores the famous **Titanic dataset** from Kaggle.  
It focuses on data cleaning, exploratory data analysis (EDA), and visualizations.  
Later steps will include predictive modeling.

## 📊 Steps in the Project
- **Data Cleaning & Preprocessing**: handled missing values, converted types, engineered features.
- **Exploratory Data Analysis (EDA)**: summary statistics, group-based insights (survival by gender/class).
- **Visualization**: key patterns using Seaborn & Matplotlib (heatmaps, bar plots, correlations).

## 🛠 Tools & Libraries
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## 📂 Repository Structure
- `notebooks/` → analysis in Jupyter Notebook
- `images/` → visualizations from the analysis
- `requirements.txt` → list of dependencies

## 🚀 Next Steps
- Build predictive models (Logistic Regression, Random Forest, XGBoost)
- Evaluate accuracy and compare performance

## 📎 Dataset
The dataset is available on [Kaggle Titanic: Machine Learning from Disaster](https://www.kaggle.com/c/titanic).
